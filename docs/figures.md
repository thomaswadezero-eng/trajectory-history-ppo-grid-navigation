# Paper tables and figures

Released per-seed inputs and descriptive summaries support numerical review of the BARN four-method, Progress/forward, component, PBRS, external-baseline, A* branch and MovingAI comparisons. Existing inferential CSVs are retained as historical numerical outputs; the independent checker does not rerun their tests.

The final editable sources, complete auxiliary inputs and exact plotting/artwork scripts for **Figures 1–5** are not all present. This release does not claim exact regeneration of those figures, and no old image or suggestively named script is substituted. Method settings can be inspected in the formal reference implementations; numerical table reconstruction is separate from exact graphical reproduction.

The manuscript is in preparation (2026). No DOI, publication record, public release date, Git commit or tag is invented. Version identifiers should be obtained from the actual Git history of the copy used, after publication, rather than from a fabricated value in this document.
